# Portfolio project entry

**Title:** Reading Stations Explorer

**Short description:** A responsive reading-station catalogue for mobile and web, rebuilt from my bachelor thesis. Readers discover materials across stations, save favourites, and report missing items; administrators maintain the collection and resolve requests.

**Technologies:** Flutter, Dart, Firebase Authentication, Cloud Firestore, REST APIs, GitHub Actions.

**Context:** My bachelor project explored how to reduce the time students spend visiting individual reading stations to find materials. The portfolio rebuild turns that research into a more accessible demonstration with a clearer discovery interface, shared mobile/web code, explicit sample data, and separate backend configuration.

**Project history:** This began as my completed bachelor thesis and Flutter application. I later prepared this portfolio rebuild with AI assistance, adding shared Android/web code, a clearer interface, tests, and publication tooling. The new implementation is documented separately from the original degree assessment.

**Design improvements:** Responsive navigation, combined search and filters, personal shelf, availability labels, clearer admin forms, request status tracking, and deliberate separation of sample data from a live backend.

**Engineering improvements:** Typed models, separate UI/state/backend layers, no database writes during reads, owner-specific request access, server-enforced admin claims, reproducible checks, and publication scanning.

**Results:** Use the validation report for verified results. The public demo demonstrates workflows with fictional data. Do not claim current campus adoption, real inventory, performance metrics, or new user acceptance results without evidence.
